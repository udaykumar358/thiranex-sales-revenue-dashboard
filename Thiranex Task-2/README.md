# Customer Segmentation Dashboard

## Project Overview
This project analyzes customer income and spending behavior
using Python and K-Means clustering.

## Features
- Interactive Streamlit dashboard
- Customer segmentation using K-Means
- Customer income and spending visualization
- Customer data table
- Download segmented customer data as CSV

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit

## Installation

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## Run the Dashboard

```bash
python -m streamlit run app.py
```

Open the local URL shown in the terminal.

## Dataset
The current version uses sample customer data
for demonstration and testing.
